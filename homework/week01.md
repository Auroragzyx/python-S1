## 作业

### 初级（必做，约 35 分钟）

1. 在 `code/week01/` 新建 `hello.py`，**手打**下面三行输出（不许复制）：
   - 你的名字
   - 今天的日期
   - 这 18 周想达到的目标（一句话）
   
   然后在终端运行 `python hello.py`，确认看到三行。

2. 打开 Python 交互模式（终端输入 `python`），依次计算并记录结果到 `notes/week01.md`：
   ```python
   (3 + 4) * 2
   2 ** 10
   7 // 2
   7 % 2
   10 / 4
   ```
   每行写一句人话解释（例如 `//` 是“整除，只要整数部分”）。

3. 下面代码有 3 处错误，复制到 `bug.py` 里改到能运行：
   ```python
   name = "小明
   print(name)
   age = 18
   print("年龄: " + age)
   ```
   改完在笔记里写：每处错是什么类型（引号 / 类型 / 缩进？）。

**验收**：`python hello.py` 和 `python bug.py` 都不报错；能说出 `int`、`float`、`str` 各存什么。

### 中级（必做，约 65 分钟）

写 `profile.py`：

1. 用变量保存：姓名、年龄、身高（米）、体重（公斤）。
2. 计算出生年份（用 `2026 - 年龄`）和 BMI：`体重 / 身高 ** 2`。
3. 用 f-string 输出一张信息卡，要求：
   - BMI 保留 2 位小数；
   - 至少用一次 `=` 分隔线（例如 `print("=" * 30)`）；
   - 输出里包含姓名、出生年份、BMI。
4. 再写一个 `profile_input.py`，把姓名、年龄、身高、体重改成 `input()` 输入，输出同样的信息卡。

示例运行（数字可以不同）：

```
==============================
姓名：小明
出生年份：2008
身高：1.75 m
体重：70.0 kg
BMI：22.86
==============================
```

**提示**：`input()` 拿到的是字符串，做数学运算前要 `int()` 或 `float()`。

**验收**：身高 1.75、体重 70 时 BMI 约为 22.86；输入 1.8 这种小数不报错。

### 高级（挑战，约 40 分钟）

写 `bill.py`：餐厅账单计算器。

1. 输入：单价、数量、折扣率（如 `0.88`，输入 `1` 表示不打折）、小费比例（如 `0.1`）。
2. 计算并输出：
   - 小计 = 单价 × 数量
   - 折后价 = 小计 × 折扣率
   - 小费 = 折后价 × 小费比例
   - 总计 = 折后价 + 小费
3. 所有金额保留 2 位小数，输出成一张类似收据的清单。
4. 在 `notes/week01.md` 里写 3 组测试数据及你手算的结果，和程序输出对一遍。

**说明**：这一题先不要求处理“输入 abc”这种错误（第 7 周才学异常），程序崩了也没关系，但要能说出崩在哪一行。

**验收**：3 组数据的结果与手算一致；金额没有出现一长串小数。
