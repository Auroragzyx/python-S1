## 作业

### 初级（必做，约 35 分钟）

1. `slices.py`：给定 `s = "Python3-2026"`，用代码输出并标注每一行是什么：
   - 长度
   - 前 7 个字符
   - 后 4 个字符
   - 反转字符串
   - 从 `-` 后面的部分
   - `"3"` 是否在 `s` 里（输出 True/False）
   
   要求：**先手写答案再运行**，把预期和实际不一致的地方记到笔记。

2. `username.py`：输入 `"  Aurora_GZYX  "`（前后有空格、大小写混合），输出规范化后的用户名：去空格 + 全小写。再输出：
   - 用户名长度
   - 用户名中 `a` 出现的次数
   - 把下划线替换成点号的结果
   - 用 `-` 把 `["python", "s1", "2026"]` 连接起来的结果

**验收**：切片结果正确，不越界；能说出 `strip()` 和 `replace()` 各做了什么。

### 中级（必做，约 65 分钟）

写 `text_stats.py`：输入一段英文（例如 `"Practice makes perfect. Python makes it fun."`），输出：

1. 原始长度、去掉首尾空格后的长度；
2. 单词个数（按空格切分即可）；
3. 每个元音 `a e i o u` 出现的次数（用 `count`，大小写都要算）；
4. 把这段话变成首字母大写（`title()`）、全大写、全小写各一行；
5. 用 `=` 做一条 40 字符宽的分隔线，标题居中显示；
6. 手机号脱敏：输入 `13812348888`，输出 `138****8888`（用切片，不许手写固定结果）。

示例：

```
============ 文本统计 ============
原长度：46
去空格后：45
单词数：7
a: 3  e: 4  i: 2  o: 2  u: 1
...
```

**验收**：输入带前后空格的句子结果仍正确；脱敏对任意 11 位手机号都成立。

### 高级（挑战，约 40 分钟）

写 `template.py`，做两件事：

1. **批量生成通知**：给定模板
   ```
   尊敬的 {name}，您本月话费为 {cost} 元，余额 {balance} 元，请及时充值。
   ```
   用 3 个用户的数据循环生成 3 句话（循环没学可以先手写 3 次，下周再改循环）。金额保留 2 位小数。
2. **对齐表格**：输出 3 行“姓名 / 金额 / 备注”，要求金额右对齐、姓名左对齐、列宽固定，看起来整齐：
   ```
   姓名        金额      备注
   张三       25.00     午饭
   李四      128.50     打车
   ```
3. **密码强度**（选做，+10 分钟）：输入密码，输出“弱 / 中 / 强”：
   - 长度 < 6：弱
   - 长度 ≥ 8 且同时有字母和数字：强
   - 其他：中
   
   提示：可以用 `any(ch.isdigit() for ch in pwd)`，看不懂就先用循环数一数。

**验收**：表格三列对齐；同一份数据改金额后不用改格式代码。
