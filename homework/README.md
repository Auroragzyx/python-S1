## 每周固定动作

1. 读当周作业顶部教程，跟着敲一遍。
2. 初级 → 中级 → 高级，**卡 20 分钟就记下来，先往后做**。
3. 代码放 `code/weekXX/`。
4. 更新 [PROGRESS.md](../PROGRESS.md)。
5. 写 `notes/weekXX.md`，提交 Git：
   ```
   weekXX: 完成初级和中级
   ```

时间不够：保初级和中级，高级可以延到复盘日或毕业后再补。**不要为了勾选而抄答案。**
