## 作业

### 初级（必做，约 35 分钟）

1. `scores.py`：成绩列表 `[88, 92, 79, 95, 67, 88, 100, 73]`
   - 输出总分、平均分（保留 2 位）、最高分、最低分、人数；
   - 从高到低排序输出；
   - 输出前三名和后两名（切片）；
   - 在末尾追加 `85`，把第一个 `88` 改成 `90`，删除最低分，再输出一次列表。
   
   不允许把结果直接写成 `print(88)`，必须用列表方法/内置函数算出来。

2. `for_list.py`：用 `for` 输出列表时带上编号，格式：
   ```
   1. 88
   2. 92
   ```
   提示：`enumerate(scores, start=1)`。

3. 元组练习：定义 `point = (3, 4)`，用拆包取出 x、y，计算它到原点的距离（`(x**2 + y**2) ** 0.5`）。再尝试 `point[0] = 5`，把报错原文记到笔记，并写一句“为什么”。

**验收**：知道 `append` / `insert` / `remove` / `pop` / `del` 的区别；能解释元组为什么不能改。

### 中级（必做，约 65 分钟）

`todo.py`：用列表做一个“待办清单”，**这周先不用菜单和 `if`**，按顺序执行并打印：

1. 初始 5 条任务；
2. 用 `for` + `enumerate` 打印；
3. 添加一条 `"复习列表"`；
4. 把第 2 条改成 `"[已完成] 买牛奶"`；
5. 删除第 3 条；
6. 用 `len()` 输出剩余条数；
7. 输出“未完成”的任务：遍历列表，跳过以 `[已完成]` 开头的（这里需要一点 `if`，可以照抄下面提示）。

提示：

```python
for task in todos:
    if not task.startswith("[已完成]"):
        print(task)
```

**验收**：每一步打印前后列表，能看出数据怎么变；`pop` 和 `remove` 至少各用一次。

### 高级（挑战，约 45 分钟）

`names.py`：

1. 两个班名单：
   ```python
   class_a = ["小明", "小红", "小刚", "小明", "小美"]
   class_b = ["小红", "小丽", "小刚", "小强"]
   ```
   用集合求：并集、交集、只在 A 班的人、只在 B 班的人，并输出人数。
2. **去重但保留顺序**：把 `class_a` 变成没有重复、顺序不变的列表。提示：可以新建空列表，`for` 判断 `not in` 再 `append`。
3. **词频统计**：给定一句话 `"the cat and the dog and the bird"`，统计每个单词出现次数并输出（只用列表和 `count` 也行，下周学字典再重写）。
4. 思考并写进笔记：为什么集合去重后顺序不可靠？什么场景该用列表、什么场景该用集合？

**验收**：能说出 `set_a & set_b`、`|`、`-` 各是什么；去重后的顺序与第一次出现的顺序一致。
