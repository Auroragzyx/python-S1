## 作业

### 初级（必做，约 50 分钟）

在 `project/app/ui/` 下建界面，复用第 13 周的 `db.py` / `service.py`：

1. `main_window.py`：900×600 主窗口，标题“小账本 v1.0-dev”，加载 `init_db()`，关闭时销毁连接。
2. 记账页表单：
   - 日期 `Entry`（默认今天）；
   - 类型 `Combobox`（收入/支出）；
   - 分类 `Combobox`（按类型联动，从数据库读）；
   - 金额 `Entry`；
   - 备注 `Entry`；
   - “新增”按钮。
3. 点“新增”：
   - 校验金额（转成分的整数、> 0）、日期格式、分类必选；
   - 调 `service.add_record(...)`；
   - 成功清空金额/备注并刷新表格；失败弹 `showerror`，不写库。

**验收**：新增 3 条后，用 DB Browser 打开数据库能看到数据；金额 25.00 存成 2500；输错不写库。

### 中级（必做，约 80 分钟）

1. 表格：`Treeview` 显示当前月记录（日期、类型、分类、金额、备注），默认本月，金额显示元。
2. 月份筛选：`Combobox` 选 `2026-09` / `2026-10` 等（从数据库已有月份取），切换即刷新。
3. 选中行回填表单；按钮改为“新增 / 保存修改 / 删除”：
   - 保存修改：更新选中记录，刷新表格；
   - 删除：`askyesno` 确认，删除后刷新并清空表单；
   - 新增模式与编辑模式要有视觉区分（例如标题变成“编辑记录 #12”）。
4. 所有数据库操作包在 `try/except` 里，出错弹窗并写日志，程序不崩。

**验收**：增→选→改→删→再增，表格和数据库都正确；切换月份不会把编辑状态搞乱；删除后 id 不会错位。

### 高级（挑战，约 50 分钟）

1. 统计页：
   - 三个数字卡片：本月收入、支出、结余（元，两位小数）；
   - 分类汇总 `Treeview`：分类、金额、占比；
   - 切到统计页时自动刷新。
2. “导出 CSV”按钮：导出当前选中月份，`utf-8-sig`，成功提示文件路径。
3. 空数据处理：某月没有记录时，表格显示“本月暂无记录”，统计显示 0.00，不报错。
4. 把 `app/ui` 和 `service` 的调用关系画成一张图放进笔记，标出哪些地方可能抛异常。

**验收**：统计数字与手算一致；导出的 CSV 能直接双击用 Excel 打开；空月份不崩。
